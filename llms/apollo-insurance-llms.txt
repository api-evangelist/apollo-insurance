# APOLLO Insurance

> APOLLO Insurance (APOLLO Insurance Agency Ltd., apollocover.com) is a Vancouver-founded Canadian
> digital insurance brokerage and MGA-style distribution platform selling personal and small-commercial
> coverage entirely online. It does not underwrite; it distributes on commission for A+ to A- rated
> Canadian carriers. Its distinctive business is embedded tenant insurance for REITs and property
> managers — automated resident enrolment at lease signing, renewal handling, and real-time
> building-level compliance tracking through a Yardi integration and its CoverTrack product.
> APOLLO is one of very few Canadian insurance organizations that publishes a genuine, anonymously
> readable developer portal with downloadable OpenAPI definitions.

## What you can actually do with this API

Of the four canonical insurance API verbs, APOLLO covers QUOTE and the front half of BIND.
There is no ISSUE endpoint and no FNOL/claims endpoint anywhere in the public surface.
"Create an application" does not bind a policy — it returns a `quoteLink` into the affiliate's
co-branded APOLLO launchpad where the consumer completes purchase and pays.
Only the tenant (renter) line is exposed: the path parameterizes `insuranceType`, but the
documentation states only `tenant` is currently available. None of APOLLO's homeowner, condo,
landlord, pet, general liability, professional liability or D&O products have an API.
Every call is partner-scoped — an `affiliateId` (a co-branded APOLLO subdomain) or a
`partnerId`, plus an `x-api-key` token APOLLO issues by hand. There is no self-serve credential
path and no consumer-facing API. Open docs, closed credentials.

## APIs

- [APOLLO Affiliates API](https://docs.apollocover.com/docs/public-affiliate-api/a8a7ea17b0889-affiliates-api): Current affiliate surface. Quote an application, create an application. Base: https://fpl95knwc1.execute-api.ca-central-1.amazonaws.com/1_0_0
- [APOLLO Public API - Affiliates](https://docs.apollocover.com/docs/affiliate-api/18a87d4863056-public-api-affiliates): Superseded generation, still published, paths hardcoded to /tenant/. Same hosts.
- [APOLLO CoverTrack API](https://docs.apollocover.com/docs/covertrack-api/fu18p9wlkzenb-cover-track-api-s): Tenant-insurance compliance for REITs and property managers. Base: https://api.covertrack.ca

## Operations

- `public-api-affiliates-quote-post` — POST /api/affiliates/{affiliateId}/{insuranceType}/quote — price a tenant application; returns premiums, taxes, Stripe fees, totals and policyExpiryDate
- `public-api-affiliates-application-post` — POST /api/affiliates/{affiliateId}/{insuranceType}/application — create a pre-filled application; returns `data.quoteLink`
- `get-compliance-status` — GET /compliance/{partnerId}/{propertyId}/{tenantId} — one tenant's compliance status
- `get-compliance-partnerId-propertyId` — GET /compliance/{partnerId}/{propertyId} — every tenant of a property (unbounded array, no pagination)
- `post-quote-tenant-partnerId` — POST /quote/tenant/{partnerId} — CoverTrack tenant quote
- `post-compliance-callback-example` — specification only, not a callable endpoint: the payload APOLLO POSTs to a partner destination on a policy event
- `post-api-affiliates-affiliateId-tenant-quote`, `post-affiliates-affiliateId-application` — superseded generation

## Authentication and environments

- Header `x-api-key`, issued by hand by an APOLLO contact. Separate tokens for test and production.
- Affiliates test: https://o73td82enk.execute-api.ca-central-1.amazonaws.com/1_0_0 — production: https://fpl95knwc1.execute-api.ca-central-1.amazonaws.com/1_0_0 — plus a Stoplight hosted mock server.
- CoverTrack test: https://api.covertrack-dev.ca — production: https://api.covertrack.ca
- No OAuth, no OIDC, no scopes, no /.well-known/ discovery on any host.
